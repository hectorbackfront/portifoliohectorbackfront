# 🚀 3D Portfolio Template

**Um portfólio 3D com editor visual — pronto pro GitHub Pages em minutos.**

---

## O que vem no pacote

- `editor.html` — Editor visual com preview ao vivo
- `portfolio.html` — O portfólio final (template)
- `README.md` — Este arquivo

---

## Como usar

### 1. Abra o editor
Abra o arquivo `editor.html` no seu navegador (Chrome ou Edge recomendado).

> ⚠️ Abra os dois arquivos na **mesma pasta**. O editor carrega o `portfolio.html` em um iframe ao lado.

### 2. Personalize tudo
Use o painel da esquerda para editar:
- **Identidade** — nome, tagline, cor de destaque, descrição, estatísticas
- **Skills** — tecnologias com barra de nível ajustável
- **Projetos** — título, descrição, stack, links GitHub e demo
- **Contato** — links de email, GitHub, LinkedIn, Instagram, etc.

O preview atualiza em tempo real enquanto você edita.

### 3. Exporte
Clique em **↓ Exportar HTML** — um arquivo `portfolio-seu-nome.html` será baixado.

### 4. Suba no GitHub Pages

```bash
# 1. Crie um repositório no GitHub chamado:
#    seuusuario.github.io

# 2. Renomeie o arquivo exportado para index.html

# 3. Faça o upload do index.html para o repositório

# 4. Acesse: https://seuusuario.github.io
```

Pronto! Seu portfólio está no ar. ✅

## Funcionalidades

- ✅ Fundo 3D com Three.js (partículas + geometrias wireframe)
- ✅ Cards com tilt 3D ao passar o mouse
- ✅ Cursor customizado com anel
- ✅ Paralaxe com movimento do mouse
- ✅ Scroll reveal animado
- ✅ Barras de skill animadas
- ✅ Responsivo para mobile
- ✅ Zero dependências externas além do Three.js (CDN)
- ✅ Um único arquivo HTML — fácil de hospedar em qualquer lugar
